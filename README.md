# AIM Proof Transfer: From Prover9 to E prover

## In this repo:
- **P9_files** contains P9 input files (.in) together with their corresponding proofs (.out).   
- **E_files** contains tptp files organised into two categories
    * **all** All AIM problems considered in this project
    * **solved** AIM problems from **all** such that there exists a strategy in **E_strat** that solves them. 
- **E_strats** contains E strategies used to solve problems from **E_files**
