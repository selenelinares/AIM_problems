# AIM Proof Transfer: From Prover9 to E prover

## In this repo:
- **P9_files** contains P9 input files (.in) and their corresponding proofs (.out).   
- **E_files** contains the corresponding tptp files organised into two categories:
    * **all**: All AIM problems considered in this project.
    * **solved**: AIM problems from **all** that can be solved by at least one strategy in **E_strat**. 
- **E_strats** contains the E strategies used to solve problems in **E_files**.
